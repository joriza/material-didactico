### 1. Fundamentos de Marcado y Estructura (HTML5)

* **Estructura semántica:** Se implementan etiquetas de HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) para la jerarquización de la información y accesibilidad.
* **Formularios avanzados:** Se diseñan formularios con validación nativa, tipos de datos específicos, elementos interactivos y atributos requeridos.

### 2. Diseño y Estilos de Interfaces (CSS3)

* **Modelo de caja y posicionamiento:** Se aplican propiedades de visualización, desbordamiento y posicionamiento estático, relativo, absoluto y fijo.
* **Diseño flexible (Flexbox):** Se configura el contenedor flexible (`display: flex`), ejes principal y transversal, alineación de elementos y adaptación a diferentes resoluciones mediante diseño responsivo.

### 3. Interactividad y Lógica del Cliente (JavaScript)

* **Sintaxis y estructuras de control:** Se utilizan variables, operadores, estructuras condicionales y bucles para la ejecución de lógica secuencial.
* **Manipulación del DOM:** Se seleccionan elementos del documento, se modifican sus propiedades y se gestionan eventos de usuario (clics, entradas de teclado, envío de formularios).
* **Funciones y asincronismo:** Se estructuran bloques de código reutilizables mediante funciones y se introducen conceptos de asincronismo para la gestión de datos.

### 4. Persistencia de Datos y Servidor (Local y MySQL)

* **Almacenamiento en el navegador:** Se utiliza la API de `LocalStorage` y `SessionStorage` para guardar, recuperar y eliminar información estructurada en formato JSON.
* **Bases de datos relacionales:** Se introducen conceptos de almacenamiento estructurado, tablas, registros y campos en entornos relacionales.
* **Conexión y consultas SQL:** Se implementa la conexión hacia una base de datos MySQL mediante sentencias SQL para realizar operaciones de consulta y manipulación de información (`SELECT`, `INSERT`, `UPDATE`, `DELETE`), vinculando las peticiones de la interfaz con el almacenamiento permanente.
