### 1. Estructura de páginas web (HTML)

* **Etiquetas básicas:** Se usan etiquetas de HTML para organizar el contenido: títulos, párrafos, imágenes, enlaces y listas.
* **Formularios simples:** Se crean formularios con campos de texto, botones y casillas para que el usuario cargue datos.

### 2. Estilos y diseño (CSS)

* **Colores y tipografía:** Se aplican colores de fondo y de texto, tamaños de letra y fuentes para mejorar la presentación.
* **Espaciado y bordes:** Se ajustan márgenes, separación interna y bordes para que la página se vea ordenada.

### 3. Interactividad básica (JavaScript)

* **Variables y operaciones:** Se usan variables para guardar datos y operar con ellos (sumas, concatenaciones, comparaciones).
* **Eventos simples:** Se programan acciones que se disparan al hacer clic en un botón o al enviar un formulario, mostrando mensajes o modificando elementos de la página.

### 4. Guardado de información en el navegador

* **Almacenamiento local:** Se guarda información en el navegador usando LocalStorage para que permanezca después de cerrar la página.
* **Consulta y eliminación:** Se recuperan y se borran los datos guardados localmente para mantener la información actualizada.
